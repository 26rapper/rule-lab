# 규칙 연구실 (Rule Lab) — 화면 3판 (2026-11-22)

새 매매 규칙을 찾는 과정을 보여 주는 한 장짜리 화면이에요. 화면은 일곱 개예요(요약 · 볼 곳 · 모은 글 · 고르기 · 후보 · 실험 · 기록).

## 파일

| 파일 | 내용 | 바꿀 때 |
|---|---|---|
| `index.html` | 화면. 글과 숫자는 아래 자료 파일 여섯 개를 읽어서 그려요. **이 파일 안에는 자료의 글이 없어요.** | 화면 모양을 고칠 때만 |
| `home.json` | 요약 화면의 글: 큰 숫자 아래 뜻 글 · 단계마다 한 줄 · 지금 확인할 일 · 날마다 기록 · 앞으로 진행할 일 | 자료가 바뀔 때마다 |
| `data.json` | 한 줄 소개 · 기준 시각 · 전체 과정(흐름) · 볼 곳 · 고르는 기준 · 실험 요약 · 조사 기록 · 용어 풀이 · `가림 표시` 문장 | 자료가 바뀔 때마다 |
| `cells.json` | 실험 하나하나(순서 · 상태 · 이름 · 있으면 `기다리는 것` · `채택`) | 실험이 바뀔 때 |
| `inbox.json` | 모은 글(요약 숫자 · 곳마다 모은 수 · 글마다 날짜 · 곳 · 쉬운 제목 · 분류 · 까닭) | 글을 새로 모을 때 |
| `candidates.json` | 실험 후보와 떨어뜨린 것(걸린 기준 · 까닭 · 어느 글에서 왔는지) | 고르기를 할 때 |
| `extra.json` | 달라진 것 · 이번에 열지 않은 곳 · 화면에서 바꿔 보이는 말 | 자료가 바뀔 때마다 |
| `icon.svg` | 브라우저 탭 그림 | 그대로 |
| `groo.json` | 올릴 곳 설정(주소는 여기에만 있어요) | 그대로 |

자료를 바꿀 때는 **자료 파일 여섯 개만** 바꾸면 돼요. `index.html` 은 건드리지 않아도 돼요.

## 요약 화면 (다섯 영역)

차례는 지금 전체 현황 → 지금 확인할 일 → 앞으로 진행할 일 → 전체 진행 단계 → 자료 검토 현황이에요. 넓은 화면(폭 900 이상)에서는 '지금 확인할 일'이 왼쪽, '앞으로 진행할 일'과 '전체 진행 단계'가 오른쪽에 나란히 놓여요.

- **숫자는 화면이 세요.** 모은 글 = `inbox.json` 요약의 `모은 글` · 자세히 본 글 = 요약의 `더 볼 것` · 실험 후보 = `candidates.json` 의 `후보` 개수 · 지금 단계 = `data.json` 흐름에서 상태가 `진행 중`인 단계 번호. 분류 막대와 검토 비율도 요약 숫자로 그려요.
- **요약 한 문장**: `home.json` 의 `요약 한 문장` 이 비어 있으면 숫자로 문장을 만들어요.
- **자세히 본 글의 결과**: `candidates.json` 의 `떨어뜨린 것` 가운데 `온 글` 이 있는 것을 `걸린 문` 별로 세요.
- **지금 확인할 일 · 앞으로 진행할 일**: `home.json` 에 갈래(열쇠)가 아예 없으면 그 갈래는 통째로 안 보이고, 열쇠는 있는데 비어 있으면 "없어요"가 나와요. 항목은 제목과 한 줄 까닭만 보이고 누르면 펼쳐져요.
- **전체 진행 단계**: 상태는 `data.json` 흐름의 `상태` 그대로예요(화면 말만 `확인 대기` → 확인 기다림, `준비 전` → 시작 전, `끝남` → 완료). 지금 하는 단계만 크게 보이고 `home.json` 의 한 줄이 붙어요.

## 알아 둘 것

- **가린 글**: 자료에서 `■` 로 채운 곳은 화면에서 모자이크 막대로 보여요. 막대 길이는 `■` 개수를 따라요(최대 18개 길이). 원래 글은 어느 파일에도 없어요. 맨 위와 맨 아래의 안내 문장은 `data.json` 의 `가림 표시` 예요.
- **없는 자료는 덩어리째 안 보여요.** `data.json` · `cells.json` 은 꼭 있어야 해요(없으면 "자료를 불러오지 못했어요"가 떠요). 나머지 넷은 없어도 화면이 열리고, 그 자료로 그리는 덩어리만 빠져요.
- **화면마다 맨 위에 숫자 요약 줄**이 있어요. 모은 글 화면에서는 그 숫자 칸이 거르기 단추예요(누르면 그 분류만 보여요).
- **색**: 밝은 바탕이 기본이에요. 기기 설정이 어두워도 밝게 열려요. 맨 아래 '어두운 바탕으로 보기' 단추로만 바뀌고, 고른 값은 그 기기에만 기억돼요. 색 값은 `index.html` 맨 위 `:root` 두 줄에 있어요. 바깥 글꼴 · 바깥 스크립트 · 바깥 요청은 없어요.
- **자료 파일 이름**은 `index.html` 의 `const FILES = …` 한 줄에 있어요. 이름을 바꾸면 그 줄도 맞춰요.
- 이 폴더의 `index.html` 을 PC에서 바로 열면 자료를 읽지 못해요("웹 주소로 열어야 자료가 보여요"가 떠요). 웹 주소로 올린 뒤에 보여요.
- 주소 끝에 `#inbox` 처럼 화면 이름을 붙이면 그 화면이 바로 열려요(`home` · `sources` · `inbox` · `criteria` · `cands` · `experiments` · `log`).
- 요약 화면에서 '달라진 것' 표는 빠졌고, 기록 화면에 그대로 있어요.
