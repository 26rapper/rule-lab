# 규칙 연구실 (Rule Lab)

새 매매 규칙을 찾는 과정을 그대로 보여 주는 기록이에요. 세부 내용 일부는 일부러 가려 두었어요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면. 글꼴 · 스크립트 · 그림을 바깥에서 불러오지 않아요. 자료의 글은 이 파일에 적혀 있지 않아요. |
| `data.json` | 화면에 보이는 글과 숫자 한 벌 |
| `cells.json` | 실험 목록 (순서 · 상태 · 이름) |
| `icon.svg` | 아이콘 |
| `groo.json` | 그루스튜디오 카드에 쓰는 정보 |

## 자료를 바꿀 때

`data.json` 과 `cells.json` 두 파일만 바꿔서 올리면 돼요. 화면은 열릴 때마다 이 두 파일을 새로 읽어요. `index.html` 은 고칠 필요가 없어요.

- 키 이름과 모양은 그대로 둬요. 목록은 길이가 달라져도 돼요.
- 가릴 글은 자료에서 `■` 로 바꿔 넣어요. 화면은 `■` 가 이어진 곳을 모자이크 막대로 그려요. 화면이 글을 가려 주는 것이 아니라, 처음부터 자료에 원래 글이 없어야 해요.
- 자료 파일의 이름을 바꾸려면 `index.html` 아래쪽 `FILES` 한 줄만 고쳐요.

## 내 컴퓨터에서 볼 때

`index.html` 을 두 번 눌러서 열면 화면 틀만 뜨고 "웹 주소로 열어야 자료가 보여요"라고 나와요. 브라우저가 내 컴퓨터의 파일끼리는 서로 읽지 못하게 막기 때문이에요. 웹 주소(깃허브 페이지)로 올린 뒤에 보거나, 이 폴더를 작은 웹 서버로 띄워서 봐요.

## 주소가 바뀔 때

`index.html` 에는 주소가 적혀 있지 않아요. `groo.json` 의 `url` 과 `icon.src` 두 줄만 고치면 돼요.
