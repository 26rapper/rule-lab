# 규칙 연구실 (Rule Lab) — 화면 2판 (2026-11-22)

새 매매 규칙을 찾는 과정을 보여 주는 한 장짜리 화면이에요. 화면은 일곱 개예요(요약 · 볼 곳 · 모은 글 · 고르기 · 후보 · 실험 · 기록).

## 파일

| 파일 | 내용 | 바꿀 때 |
|---|---|---|
| `index.html` | 화면. 글과 숫자는 아래 자료 파일 다섯 개를 읽어서 그려요. **이 파일 안에는 자료의 글이 없어요.** | 화면 모양을 고칠 때만 |
| `data.json` | 한 줄 소개 · 기준 시각 · 전체 과정(흐름) · 볼 곳 · 고르는 기준 · 실험 요약 · 조사 기록 · 용어 풀이 · `가림 표시` 문장 | 자료가 바뀔 때마다 |
| `cells.json` | 실험 하나하나(순서 · 상태 · 이름 · 있으면 `기다리는 것` · `채택`) | 실험이 바뀔 때 |
| `inbox.json` | 모은 글(곳마다 모은 수 · 글마다 날짜 · 곳 · 쉬운 제목 · 분류 · 까닭) | 글을 새로 모을 때 |
| `candidates.json` | 실험 후보와 떨어뜨린 것(걸린 기준 · 까닭 · 어느 글에서 왔는지) | 고르기를 할 때 |
| `extra.json` | 달라진 것 · 확인이 필요한 것 · 앞으로 진행될 일 · 이번에 열지 않은 곳 · 화면에서 바꿔 보이는 말 | 자료가 바뀔 때마다 |
| `icon.svg` | 브라우저 탭 그림 | 그대로 |
| `groo.json` | 올릴 곳 설정(주소는 여기에만 있어요) | 그대로 |

자료를 바꿀 때는 **자료 파일 다섯 개만** 바꾸면 돼요. `index.html` 은 건드리지 않아도 돼요.

## 알아 둘 것

- **가린 글**: 자료에서 `■` 로 채운 곳은 화면에서 모자이크 막대로 보여요. 막대 길이는 `■` 개수를 따라요(최대 18개 길이). 원래 글은 어느 파일에도 없어요. 맨 위와 맨 아래의 안내 문장은 `data.json` 의 `가림 표시` 예요.
- **없는 자료는 덩어리째 안 보여요.** `data.json` · `cells.json` 은 꼭 있어야 해요(없으면 "자료를 불러오지 못했어요"가 떠요). `inbox.json` · `candidates.json` · `extra.json` 은 없어도 화면이 열리고, 그 자료로 그리는 덩어리(달라진 것 · 확인이 필요한 것 · 앞으로 진행될 일 · 떨어뜨린 것)는 빠져요. 모은 글과 후보 화면에는 "아직 없어요"가 나와요. 파일 안에서 묶음 하나를 빼도 그 덩어리만 빠져요.
- **'그전에 달라진 것까지 보기'** 는 `extra.json` 의 `달라진 것` 에 `묶음`(자료 시각)이 둘 이상일 때만 보여요. 요약 화면에는 가장 새 묶음만, 기록 화면에는 전부 나와요.
- **색**: 기기 설정과 상관없이 늘 밤 색 한 가지예요(`index.html` 맨 위 `:root` 한 곳). 바깥 글꼴 · 바깥 스크립트 · 바깥 요청은 없어요.
- **자료 파일 이름**은 `index.html` 의 `const FILES = …` 한 줄에 있어요. 이름을 바꾸면 그 줄도 맞춰요.
- **화면이 읽는 열쇠 이름**: `data.json` 은 `기준시각` · `한줄` · `알림` · `가림 표시` · `흐름` · `볼곳` · `고르는기준` · `실험기록` · `조사기록` · `풀이`. 모은 글이 어느 '떨어뜨린 것'과 이어지는지는 `inbox.json` 글의 `id` 와 `candidates.json` 의 `온 글` 로 맞춰요. 분류와 걸린 기준을 화면에서 다른 말로 보이려면 `extra.json` 의 `분류 보이는 말` · `걸린 문 보이는 말` 에 적어요.
- 이 폴더의 `index.html` 을 PC에서 바로 열면 자료를 읽지 못해요("웹 주소로 열어야 자료가 보여요"가 떠요). 웹 주소로 올린 뒤에 보여요.
- 주소 끝에 `#inbox` 처럼 화면 이름을 붙이면 그 화면이 바로 열려요(`home` · `sources` · `inbox` · `criteria` · `cands` · `experiments` · `log`).
